# Public demo example

Open the HTML in `01-core-product/webui/` directly in a browser. The included sample content demonstrates:

- C/E/S evidence separation;
- historical-scene storytelling;
- per-frame image prompts;
- an aggregate video-storyboard prompt;
- person/object/space/light/style continuity;
- a delivery QA checklist.

The example is a demonstration artifact, not a complete historical database.
